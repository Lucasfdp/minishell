🧠 Core Concepts You’ll Tackle
Input – Use readline() to get user input (bonus: it gives you history for free).

Parsing – You’ll need to:

Handle quotes (', ")

Handle redirections (>, >>, <, <<)

Handle pipes (|)

Expand environment variables ($VAR)

Tokenize smartly (respecting quotes, etc.)

Execution – Once parsed:

Set up correct piping between commands.

Use fork(), execve(), and dup2() to create the right execution environment.

Handle built-in commands (without forking).

Builtins – You must implement at least:

cd, echo, pwd, export, unset, env, exit

Environment Handling – You’ll manage a copy of the envp array and use it in your execve() calls and your own logic.

Signals – Handle CTRL+C, CTRL+D, CTRL+\ properly. Your shell should behave like a real shell.

Redirections – This includes:

Redirecting input/output.

Handling heredocs (<<) — with attention to signals!

Exit Status – Track and return the correct exit status of commands and shell exit codes.

🛠️ Mini Checklist
 readline() integration

 Smart tokenizer

 Quote & variable expansion

 AST (Abstract Syntax Tree) or command table structure

 Pipe management

 Redirection handling

 Builtins (at least 7)

 Environment handling

 Signals and heredoc quirks

 Exit status and error messages
