## Builtin: `env`

### Overview

`env` prints the environment variables in the current shell session. Unlike `export`, it only shows variables that are currently defined and exported.

### Edge Cases

* **Extra arguments** → not required in minishell (Bash uses them to run commands in a modified environment).
* **Uninitialized environment** → should print nothing.
* **Order of variables** → does not have to be sorted.

### Things to Test For

1. `env` in fresh shell → prints inherited environment.
2. After `export VAR=hello`, running `env` shows `VAR=hello`.
3. `env` with unset variable → confirms removal.
4. `env foo` → should error (if minishell does not support).


## Builtin: `env`

### Resumen

`env` muestra las variables de entorno de la sesión actual. A diferencia de `export`, solo lista las que ya están definidas y exportadas.

### Casos Especiales

* **Argumentos extra** → minishell normalmente no los admite (en Bash sirven para ejecutar comandos con entorno modificado).
* **Entorno vacío** → no debe imprimir nada.
* **Orden de variables** → no es necesario que esté ordenado.

### Casos a Probar

1. `env` en una shell recién abierta → imprime el entorno heredado.
2. Después de `export VAR=hola`, `env` debe mostrar `VAR=hola`.
3. `env` tras `unset VAR` → confirma que fue eliminado.
4. `env foo` → debe dar error (si minishell no lo soporta).
